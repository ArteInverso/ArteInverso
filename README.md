> [!IMPORTANT]
> 🧠 **Foco de Innovación: Inteligencia Artificial con Rust**
> Mi pasión principal es cerrar la brecha entre los Modelos de Lenguaje (LLMs) y el rendimiento a bajo nivel. Utilizo **Rust** para construir sistemas de recuperación de información (RAG), bases de datos vectoriales y agentes de IA que requieren máxima seguridad de memoria, concurrencia extrema y tiempos de respuesta de milisegundos, superando las limitaciones tradicionales de Python en producción.

### 🚀 Sobre Mí

- 💻 **Arquitectura:** Construcción de microservicios resilientes, sistemas distribuidos y aplicaciones web escalables end-to-end.
- ⚙️ **Core Stack:** Dominio profundo de **C# (.NET 8/9)**, **Rust** para cargas pesadas, y **TypeScript** en el frontend.
- 🤖 **Workflows de IA:** Orquestación de LLMs locales y en la nube, Prompt Engineering avanzado, integraciones con Qdrant/Pinecone y optimización de inferencia.
- 🎯 **Filosofía:** "El código seguro y rápido por defecto no es un lujo, es una necesidad."
- 💬 **Pregúntame sobre:** Patrones de diseño en .NET, concurrencia y *Borrow Checker* en Rust, o cómo implementar agentes de IA autónomos.
